# 原话账本（astrbot_plugin_dafeiyu_recall）

让 AstrBot 里的角色**翻得到聊过的原话**。

AstrBot 本体只把「查群聊历史」做成了工具，私聊这边角色翻不到任何原文——于是用户问
「我上次怎么说的」「你当时原话是什么」，它只能凭记忆摘要（如果有）现编。

这个插件把 `conversations` 表里的原文接出来，给角色一个只读的检索入口：按关键词找，
连它下一句回复一起返回，角色就能照原话答。

## 装

1. 放到 `<AstrBot>/data/plugins/astrbot_plugin_dafeiyu_recall/`
2. 在 WebUI 里启用插件
3. 把它加进人格的 `tools` 白名单（默认人格是全量工具，不用改）

## 配置

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `db_path` | 空 | 留空自动用 `<AstrBot>/data/data_v4.db`；只以 `mode=ro` 只读打开 |
| `max_quotes` | 5 | 一次最多返回几处命中（1–12） |
| `max_chars` | 120 | 每句原话保留多少字（40–300） |

## 用法

- 工具 `recall_messages(keyword, scope)`：`scope` 写「当前会话」只翻这一条聊天，写「全部」把
  QQ / 微信 / 桌宠所有会话一起翻。
- 命令 `/翻记录 关键词`：给用户手打用。

返回形如：

```
在最近 383 句对话里翻到 2 处：
1. 你：我要去上早操了，我回来啦，拜拜
   接的是 → 去吧去吧，早操别迟到…
```

## 设计取舍

- **只读**：`sqlite3.connect(f"file:{db}?mode=ro", uri=True)`，不写、不改、不删。
- **不给时间**：`conversations` 只有会话级的 `created_at/updated_at`，每条消息没有独立时间戳，
  所以不假装能给「几月几号说的」——它只保证「原话是什么」。
- **裁掉的看不见**：AstrBot 会按上下文窗口裁剪历史，库里本来就只留最近若干轮；更早的只能
  靠记忆类插件。这句限制会写进「没找到」的回复里，不硬编。
- **命中带下文**：只给用户那句没用，旁边接的是角色自己的回复，才看得出当时的语境。
